Live saving needs this page served over http://, not opened as a file.

Chrome and Edge block write access to local files for pages opened directly from disk (file://). Run this from the repo root, then open the page at the printed address instead of double-clicking the file:

python -m http.server 8000

Then open http://localhost:8000/question-review.html.

Open the question bank

Select assets/data/questions.json from this repository. In Chrome or Edge, over http://, every question you approve is written straight back to that file — no download step. Over file://, or in other browsers, you'll need to download the updated file yourself when you're done.
